# Techfest Concept Landing Page

A concept landing page created for the Techfest IIT Bombay CA web task.

## Direction
This is an original visual concept inspired by the current Techfest ecosystem, not a copy of the official website.

Design ideas:
- Black / paper / Techfest-orange visual system
- Editorial oversized typography
- Animated grid and orbital motifs
- Competition and ecosystem cards
- National zonal circuit visualization
- Strong CTA / festival-energy ending
- No 3D assets

## Tech
HTML5 + CSS3 + vanilla JavaScript.

## Run
Open `index.html`, or:

    python3 -m http.server 8000

Then open http://localhost:8000

## Deployment
Upload the files to GitHub and enable GitHub Pages from `main` / root.
